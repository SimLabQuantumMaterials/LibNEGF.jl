## Installation and Usage
Get the file `built_matrices.tar.xz`, located at `/p/project1/mat4energy/ramirez1/libNEGF/matrices/3x3/`. Extract it in your system. Let us assume this is stored in `$PATH_TO_BUILT_MATRICES`. In this repository, go to the file `setup.sh`, uncomment the block necessary to create the symbolic link to the matrices and run `./setup.sh` . This will change in the future to something more appropriate e.g. making use of Git LFS.

Finally, run:

```
./test.sh
```
